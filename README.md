# Домашнее задание 2 — выражения, динамический массив, соединения, стратегии, сериализация

Пять заданий:

1. `task1` — разбор и вычисление арифметических выражений (`Expr`).
2. `task2` — динамический массив (`DynamicArray`, `DynamicIntArray`).
3. `task3` — менеджер соединений с повторными попытками: стабильное и ненадёжное соединение, выполнение команд (`ConnectionManager`, `PopularCommandExecutor`).
4. `task4` — стратегии роста ёмкости массива: удвоение, фиксированный шаг, золотое сечение.
5. `task5` — сериализация массива в бинарный формат, CSV, JSON и XML через `SerializerFactory`.

## Запуск

Откройте проект в IntelliJ IDEA (файл `homework2.iml`) и запустите `Main`.

Исходный код взят из ветки `homework2` репозитория [wmeenw/JAVAhomework](https://github.com/wmeenw/JAVAhomework).
